# lib/worldbox — WORLD BOX 本体のドメイン構成

WORLD BOX の中核ライブラリ。ファイルはドメイン別フォルダに分けてある。

| フォルダ | 中身 |
|---|---|
| `core/` | 基盤: 乱数・イベント・セーブ・ロック・リモート・リアルタイム接続・運用（ops/metrics） |
| `world/` | ワールドそのもの: タイル・マップ生成・ロビー・空間遷移・ワープ・昼夜と季節・地形オブジェクト・インスタンス |
| `player/` | プレイヤー: プレゼンス・プロフィール・移動・スタミナとバイタル・役職・操作アフォーダンス |
| `economy/` | 経済: コイン経済とブリッジ・アイテム・ショップ・屋台・ギルドショップ・機械・コンテナ |
| `social/` | 交流: チャット・パーティ・ギルドと掲示板・国家・Discord 連携・リクエスト |
| `activity/` | 遊び: カジノ・競馬・釣り・アーケード・コンパス |
| `media/` | 演出: サウンド・エフェクト・アニメーション |

## ルール

- `x-online.ts` は `x.ts` のオンライン版（bot_kv への永続化・同期を担う対）。**ペアは必ず同じフォルダに置く**。
- 純粋ロジックは `x.ts`、オンライン接続が要る処理は `x-online.ts` に分ける。
